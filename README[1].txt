# THE BEAN LOFT — QR Menu

A polished, mobile-first static café menu website.

## Run locally

Open `index.html` directly in a modern browser.

For the best development experience, use VS Code + Live Server or any simple static server.

## Structure

- `index.html` — page structure and menu sections
- `style.css` — brand styling and responsive layouts
- `script.js` — menu data, search, filters and active category navigation
- `images/` — THE BEAN LOFT logo and transparent food/drink assets

## Brand palette

Cream: #F7F0DF
Burgundy: #8E293D
Dark Burgundy: #671D2D
Muted Rose: #B86A75
Coffee Brown: #795548
Sand: #E7D7BB

## Notes

The menu prices are entered in the HTML/JS data exactly according to the supplied menu.
All listed prices are shown in INR and the footer notes that prices are inclusive of 5% GST.

Replace `images/logo.jpg` with a higher-resolution logo PNG if you have one; the current file is the supplied logo image.
